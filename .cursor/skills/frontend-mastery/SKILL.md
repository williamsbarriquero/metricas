# Frontend Mastery

## Quando usar

- Implementação ou revisão de componentes `.tsx` / `.jsx` da SPA
- Decisões de estado, formulários, roteamento ou a11y
- Acionada por `frontend-standards.mdc`, `@rpe-developer.md` ou stack `--react`

## SSOT (leitura obrigatória)

Antes de implementar ou revisar frontend, leia integralmente:

`.cursor/knowledge/stacks/frontend.md`

## Verificação

Conforme `stack-baseline.mdc` → seção Frontend. Em `frontend/`: `npm run lint`, `npm run fmt:check`, `npx tsc -b`, `npm test`.
